# job-radar

I look for freelance work by opening five job boards every morning and
reading the listings by hand. This is the script that does it for me.

**What it will do**
- Pull job listings from open APIs (Remotive, RemoteOK, Arbeitnow, Himalayas, Jobicy)
- Filter them against my own rules
- Send what survives to Telegram
- Run on a schedule with GitHub Actions

**Status:** day 0. Nothing works yet.
